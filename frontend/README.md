# Frontend - Console terrain React/Canvas

Interface interne orientee exploitation chantier:

- saisie des parametres metriques
- lancement du pipeline facade + echafaudage
- visualisation canevas des travees et niveaux
- export des livrables techniques

## Lancement

```bash
npm install
npm run dev
```

## Variable d'environnement

- `VITE_API_BASE` (optionnel): URL API backend, par defaut `http://localhost:8000/api/v1`.
